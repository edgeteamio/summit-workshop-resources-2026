Claude

Reads · writes with a connector

1

Create a Project called Brain. Paste the short brain instructions as its instructions.

2

Project knowledge → + → GitHub → pick README.md, me.md, rules.md and people.md

3

To write back: Customize → Connectors → add GitHub’s MCP server with a brain-only token

4

Brain changed? Click Sync on the project knowledge.

Claude's GitHub integration reads private repos through the Claude GitHub app, but project knowledge is a snapshot of one branch with no history, so it needs a Sync after the brain changes. Writing back takes a custom connector: GitHub's remote MCP server at api.githubcopilot.com/mcp/ with a token in a request header. Request headers are in beta for some organizations, so it may not be available on every plan. If you add it, set its delete tools to Blocked. Personal-level instructions live under Settings → Your Claude → Instructions. Sources: support.claude.com, checked Oct 28.
