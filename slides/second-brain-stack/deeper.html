About 3 minutes. A few ideas for after today; how-tos are under "Go deeper" in RESOURCES.md. Show the EdgeTeam examples briefly: the Recording Assistant imports Zoom cloud recordings and Pocket transcripts by webhook and has its own MCP server; edgeteam-recordings lets any agent search every meeting; EdgeTeam OS is our company brain (vault, wiki, meetings, CRM, recordings) with one MCP server. Three cautions. Recording needs everyone's consent where you live. Write decisions and action items to the brain, not whole transcripts: they bloat it and carry whatever anyone said, keys included. And an MCP server is a door into your data, so put auth on it before anything else can reach it (EdgeTeam OS uses OAuth and bearer tokens). For idea 3, Claude Code's scheduled tasks run in the cloud on a repo you pick; set one up with /schedule.
