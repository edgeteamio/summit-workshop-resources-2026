How people organize them

Popular structures

PARA

Projects, Areas, Resources, Archives: sorted by how soon you’ll act

Zettelkasten

Small notes, one idea each, linked to each other

Johnny.Decimal

Numbered areas and categories, like 15.52, never more than two levels

Maps of content

Index notes that link related notes, instead of deep folders

Daily notes

One dated note a day as the inbox, sorted later

A map for agents

One index file, a few folders, an inbox. What you’ll build today.

Any of these works. Agents follow whatever your map says.

About 30 seconds. A recap after the three deep dives: name the other two so people recognize them, then land on the highlighted card, which is ours. PARA is Tiago Forte's and the most common default (projects, areas, resources, archives). Zettelkasten suits writers and researchers. Johnny.Decimal suits people who want to find any file fast. Maps of content come from Nick Milo's Linking Your Thinking and are popular with Obsidian users. Daily notes are built into Obsidian, Logseq and Tana. Also out there: GTD for tasks, and CODE (capture, organize, distill, express) as a workflow that pairs with PARA. The highlighted card is the agent-era pattern from Karpathy's LLM Wiki: one index file the agent reads first, a few folders, and an inbox. Our brain is that pattern with a light PARA flavor: projects/ for projects, notes/ for resources, inbox/ for new things. Want PARA? Ask your agent to reorganize the brain into PARA and update the map in README.md.
