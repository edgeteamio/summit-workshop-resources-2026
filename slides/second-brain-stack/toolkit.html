Quick skills.sh demo: npx skills add coreyhaines31/marketingskills. The Codex review command is in RESOURCES.md. Then the secrets card, two minutes: never paste a key into a chat or the brain, because it sits in that app's history. Agents use secrets without seeing them. op run hands a key to one command at runtime. Infisical does the same for a team with infisical run. It is open source and free for up to five users and machine accounts in total. Doppler is the hosted-only option, with doppler run. HashiCorp Vault is what big companies run on their own servers, and it can make keys that expire on their own. OpenBao is its open-source fork. TruffleHog scans a repo and its history for keys and checks which ones still work. I picked it over Gitleaks because Gitleaks now gets security patches only. SAFETY.md is the ten-minute lock-down for the brain: two-factor on GitHub, give each app only the brain repo, brain-only tokens, and an optional check that blocks keys from being committed (tested Oct 29 on Sonnet and Haiku: it blocked a fake key, and Haiku refused to bypass it with --no-verify when asked).
