Tested Oct 29 on the desktop app (0.78.1): a new Bot read the private brain on its first message through the GitHub connection. It can't push from its own computer, so it starts a cloud coding agent that commits for it (as "Cursor Agent") and reports the commit. It refused to save a fake API key to the brain, and it flagged a planted instruction in an inbox note instead of following it. If a private repo still shows a 404, save a brain-only token in its secret card and have it clone the repo. Grok Bot is SpaceXAI's personal agent (beta since Aug 11, 2026, built with the Cursor team). Each Bot runs on its own cloud computer with a browser, a terminal and a workspace folder, so it can use git like Claude Code. It runs on the desktop app and iOS/Android, and needs an X Premium tier or higher or a paid Cursor plan. Personal Bots have no instructions box, so the first message plus “remember this” does the job. Watch out: a September forum thread reports the GitHub connector showing Connected while private repos return 404, which is why the token fallback is there. Logins on its computer are shared by all your Bots. Sources: x.ai Grok Bot docs, checked Oct 28.
