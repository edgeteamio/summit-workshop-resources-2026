About 2 minutes. This is part four, the instructions: the whole protocol, and it lives in BRAIN-INSTRUCTIONS.md. Agents write decisions, preferences, facts and lessons, and skip anything the code or git already records. Every commit is labeled agent@device, so you can see who wrote what and undo it. If two devices edit the same note, the agent keeps both. These two lines come from the test run: Claude on one laptop wrote a decision, and Codex on another machine read it.
