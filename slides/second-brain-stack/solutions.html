Unbundled: today

About 2 minutes. Most tools bundle the parts: Notion is the files, the sync and the app all at once, and ChatGPT and Claude memory are second brains most of the room already has, but don't own or control, and that only one app can read. Today we unbundle them, so you can swap any part later. Memory layers sit between the two. Mem0 is an open-source memory layer with a hosted platform and OpenMemory, a local MCP server that shares one memory across tools like Claude and Cursor. Supermemory is a memory API with an MCP server and a consumer app. Cognee is an open-source memory engine that turns your data into a knowledge graph plus vector search, with an MCP server and a hosted option. They're portable across agents, but you can't read or edit the memory as files, and you're trusting their database with it. Self-hosting moves the database to your machine, but it's still a database, not files. Categories you'll hear about: all-in-one workspaces (Notion, Coda), local markdown (Obsidian), outliners (Tana, Logseq, Capacities; Logseq's new version stores notes in a database instead of markdown), everyday notes (Apple Notes, OneNote, Google Keep, Evernote), and AI-native notes (Gemini Notebook, the new name for NotebookLM since July, plus Mem and Reflect). Sync trade-offs: git keeps every version with a message saying who changed what, which is why agents handle it best. Drive and Dropbox are easy but make "conflicted copy" files. Obsidian Sync has no API for agents. Notion is a database behind an API, not files. Headless means no app at all: agents read the files directly, or through MCP or an API. Usage, for a sense of scale: Stack Overflow's 2025 developer survey had markdown files at 35%, Notion at 17% and Obsidian at 16% for documentation tools; Notion announced 100 million users in 2024.
